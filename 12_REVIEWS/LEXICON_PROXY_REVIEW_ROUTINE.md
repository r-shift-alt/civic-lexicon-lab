# Lexicon Proxy Review Routine

## Purpose

This document defines a lightweight review routine for the first lexicon pilot.

The routine is designed to answer one question quickly:
Can a small number of relevant reviewers extract practical value from the lexicon format without requiring a larger platform or heavy onboarding?

## Review Object

Use 3 draft entries for the first cycle.

Recommended entry set:
- Solidarität / Solidarity
- soziale Marktwirtschaft / social market economy
- Staatsbürgerschaft / citizenship, with civic-term note where relevant

Reason for this set:
- they create different kinds of mismatch;
- they expose whether the format can handle both institutional and value-laden terms;
- they are difficult enough to be a meaningful test.

## Reviewer Count

Target:
- 3 reviewers if possible;
- 2 reviewers is the minimum viable review set.

The goal is not statistical confidence. The goal is to produce grounded qualitative evidence and detect obvious format failures early.

## Reviewer Selection Rule

Prioritize reviewers who are close to the actual user job:
- bilingual editors;
- policy writers;
- communications staff;
- researchers or advisors who move ideas between German and English contexts.

Do not use only friends of the project or people who mainly respond to intellectual ambition.

## Pre-Review Package

Each reviewer should receive:
- a short one-paragraph explanation of the artifact;
- the 3 draft entries;
- a short instruction telling them to judge practical usefulness, not ideological agreement;
- 5 to 7 review questions.

Suggested framing note:
This is a working lexicon for politically contested terms across German and English. Please assess whether it helps with real wording, translation, framing, or explanation decisions.

## Review Steps

### Step 1: Independent Read
Ask the reviewer to read the 3 entries alone first.

### Step 2: Practical Judgment
Ask the reviewer to answer:
- Which entry was most useful?
- Which part of the format was most useful?
- Which part felt unnecessary?
- What remained unclear when trying to make a practical decision?
- Would this have changed your wording, gloss, or explanation in a real task?

### Step 3: Forced Use Test
If possible, give the reviewer one short scenario such as:
- translating a sentence for an op-ed;
- explaining a term to a mixed audience;
- choosing whether to translate literally or add a gloss.

Then ask:
- Did the entry help you choose?
- What wording would you now use?
- What warning would you carry over from the entry?

### Step 4: Format Diagnosis
Ask for judgment on:
- too dense / about right / too thin;
- too academic / practical enough;
- enough evidence / not enough evidence;
- reusable format / one-off interesting note.

### Step 5: Continuation Signal
Ask directly:
- Would you want more entries in this format?
- If yes, for what kinds of terms?
- If no, why not?

## Review Questions

Recommended compact questionnaire:
1. Did the lexicon address a problem you actually recognize?
2. Which entry component was most useful: definition, mismatch note, framing warning, examples, or recommendation?
3. Did any entry change the wording or explanation you would choose?
4. What should be cut because it adds analysis but not use?
5. What is missing for practical use?
6. Would you want more entries in this format?
7. If you would not use this, what would you use instead?

## What To Capture From Each Review

Capture in structured notes:
- reviewer type;
- whether they recognize the problem;
- whether they would reuse any part of the artifact;
- whether an entry changed a practical decision;
- what they found confusing or excessive;
- whether they want more entries.

## Decision Rule After Review

Continue if:
- at least 2 reviewers recognize the problem as real;
- at least 2 reviewers identify concrete reusable value;
- at least 2 reviewers report changed or clarified wording judgment.

Revise if:
- value is visible but the format is too dense or too analytical.

Stop or demote if:
- utility remains vague;
- reviewers cannot imagine real use;
- or producing decent entries is already too expensive.

## Time Box

The full first review cycle should stay bounded.

Recommended limit:
- entry preparation: short, manual, bounded;
- review collection: one small cycle only;
- synthesis: one review memo.

Do not let the review design become a larger project than the artifact itself.

## Output of the Review Cycle

The cycle should end with one short memo that answers:
- Is the problem real?
- Is the current format useful?
- What should be cut, tightened, or added?
- Does the lexicon continue as the lead first artifact?
