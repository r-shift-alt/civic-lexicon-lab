# Lexicon Pilot Reviewer Packet

## Purpose

This packet bundles the first three lexicon pilot drafts into one compact review object for proxy-user testing.

It is meant for bilingual editors, translators, policy writers, communications staff, and researchers who regularly move political language between German and English.

Please review this packet for practical usefulness, not ideological agreement.
The question is whether these entries help with real wording, translation, framing, or explanation decisions.

## One-Paragraph Artifact Explanation

This is a working German-English lexicon for politically contested terms that often look directly translatable but do not carry the same baggage, register, or practical meaning across contexts. Each entry is trying to help a writer, editor, or translator decide when a literal translation is safe, when a short gloss is needed, and when a familiar equivalent may quietly distort the source term.

## Review Object

Read these three draft entries:
1. `11_ARTIFACTS/LEXICON_SOLIDARITAET_ENTRY_DRAFT.md`
2. `11_ARTIFACTS/LEXICON_SOZIALE_MARKTWIRTSCHAFT_ENTRY_DRAFT.md`
3. `11_ARTIFACTS/LEXICON_STAATSBUERGERSCHAFT_ENTRY_DRAFT.md`

These were chosen because they test three different failure modes:
- register drift: `Solidarität`
- historically loaded institutional language: `soziale Marktwirtschaft`
- legal-status language versus civic-language expansion: `Staatsbürgerschaft`

## Review Instructions

1. Read the three entries independently.
2. Judge whether they would help you make a real writing, editing, translation, or explanatory choice.
3. Then use the forced-use scenario below and answer the questionnaire.
4. Keep feedback concrete. Point to wording, examples, warnings, or missing guidance.

## Forced-Use Scenario

Imagine you are editing a short English explainer for an audience that does not know German political vocabulary well.

The explainer briefly discusses:
- calls for `Solidarität` during a social-policy debate,
- a party defense of the `soziale Marktwirtschaft`,
- and a policy dispute over `Staatsbürgerschaft` reform.

For each term, decide:
- would you translate it literally,
- would you add a short gloss,
- or would you preserve the German and explain it?

Then note:
- what wording you would now use,
- what warning from the entry you would carry into the final text,
- and where the draft still leaves you uncertain.

## Compact Questionnaire

1. Did this lexicon address a problem you actually recognize?
2. Which entry component was most useful: definition, mismatch note, framing warning, examples, or recommendation?
3. Did any entry change the wording or explanation you would choose?
4. What should be cut because it adds analysis but not use?
5. What is missing for practical use?
6. Would you want more entries in this format?
7. If you would not use this, what would you use instead?

## Minimum Structured Response Format

If you want to keep notes in a compact form, use this template:

## Maintainer Use Note

This packet is intentionally small.
It should be enough to collect the first review cycle without creating a larger onboarding project.

Review output should later be compressed into one short memo covering:
- whether the problem feels real,
- whether the format is practically useful,
- what should be cut, tightened, or added,
- and whether the lexicon remains the lead first artifact.
