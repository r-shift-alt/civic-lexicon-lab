# Public Decisions Summary

## Purpose
This note extracts the contributor-relevant decisions from the internal planning process without exposing the full operator log.

It exists to answer a simple question for outside readers:
why does this repository currently look the way it does?

## Current Public-Meaningful Decisions

### 1. The project is artifact-first, not manifesto-first
The project is intentionally avoiding a public launch built around ideology, branding, or a total worldview statement.

Why this matters for contributors:
- contributions should strengthen useful artifacts, methods, and review routines;
- broad theory expansion is not the current job;
- practical value should lead, public narrative should lag.

### 2. The first artifact is a bounded German-English political concept lexicon
The current first artifact track is not a platform, dashboard, or general multilingual system.
It is a small lexicon with framing notes for politically contested concepts moving between German and English.

Why this matters for contributors:
- work should improve this bounded artifact first;
- suggestions that require more languages, broad automation, or platform infrastructure should usually wait;
- the current target is a credible small tool, not maximum coverage.

### 3. The first user group is narrow on purpose
The lexicon is currently designed for:
- bilingual or translation-adjacent political communicators,
- policy-adjacent writers,
- editors or researchers who regularly move contested concepts between German and English.

Why this matters for contributors:
- good contributions should help these users make better wording, translation, glossing, or framing decisions;
- contributions that only make sense for a vague general audience are lower priority right now.

### 4. Version one is deliberately constrained
The current MVP boundary is:
- one language pair: German ↔ English
- eight initial concepts
- manually curated entries
- explicit evidence requirements
- traceable source examples
- hard version-one exclusions

Why this matters for contributors:
- boundedness is part of the design, not a temporary inconvenience;
- if a proposal expands the artifact, it should explain why expansion is necessary now rather than later;
- reviewers should help keep the scope tight.

### 5. Evidence beats elegant synthesis
Entries are expected to rely on traceable public or policy usage rather than dictionary intuition or free-floating interpretation.

Why this matters for contributors:
- source examples are valuable contributions;
- claims about mismatch, baggage, or false equivalence should be tied to evidence;
- unsupported but plausible-sounding wording analysis is not enough.

### 6. Proof of value must come from practical use, not admiration
The project does not treat polite praise or ideological agreement as proof that the artifact is working.
The lexicon earns continuation only if users or proxy users can make better decisions with it.

Why this matters for contributors:
- useful feedback is specific, concrete, and tied to actual wording choices;
- the best review comments say what changed, what helped, what was missing, or what should be cut.

### 7. Public collaboration should stay separate from internal operator scaffolding
Not every file in the workspace is meant to be public.
The public repository is intended to foreground useful artifacts, contributor pathways, and review methods.

Why this matters for contributors:
- repository-facing documents should be legible without needing the full hidden architecture;
- contributor-facing material should focus on concrete work, not internal state management.

### 8. The lexicon remains the lead artifact only while it stays bounded and useful
A fallback exists.
If early entry drafting shows that the lexicon cannot stay credible without uncontrolled scope or maintenance burden, the project should switch attention to the campaign knowledge transfer template.

Why this matters for contributors:
- constructive skepticism is welcome;
- the project is not committed to the lexicon out of identity or sentiment;
- bounded execution and real usefulness matter more than attachment to a concept.

## What This Means for Contributions Right Now
The highest-value contributions at the current stage are:
- tightening the lexicon entry format;
- surfacing strong German and English source examples;
- identifying framing baggage or false-equivalence risks;
- stress-testing whether the first pilot concepts are the right ones;
- helping keep the artifact small, legible, and reviewable.

## Near-Term Repository Direction
The immediate public-facing path is:
1. publish clean orientation and contribution docs;
2. publish bounded lexicon design and review materials;
3. draft the first three pilot entries;
4. run a small proxy-user review loop;
5. continue only if practical value becomes visible.

## Working Conclusion
This repository is being built around a narrow practical question:
how can AI-assisted work help people handle contested political language across German and English with less distortion, less false equivalence, and more reviewable judgment?

That question is more important right now than any larger doctrine the project may eventually support.
