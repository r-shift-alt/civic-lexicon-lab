# Lexicon Minimum Research Inputs for the Pilot Set

## Purpose

This note defines the minimum preparatory research needed before drafting the first three pilot entries:
- `Solidarität` / `solidarity`
- `soziale Marktwirtschaft` / `social market economy`
- `Staatsbürgerschaft` / `citizenship`, with an explicit boundary note on when `Bürgersinn` is the more relevant civic term

The goal is not to finish all research in advance.
The goal is to define the smallest credible research package that makes the first drafting pass bounded, reviewable, and useful.

This note exists to prevent two common failure modes:
- under-researched entries that rely on intuition alone;
- over-researched entries that expand into open-ended historiography, theory, or comparative politics.

## Working Rule

A pilot entry is ready for drafting when it has:
1. one clear user-job framing;
2. one provisional mismatch claim worth testing;
3. enough traceable evidence to support at least one warning and one recommendation;
4. no unresolved research dependency that would force the draft into broad background explanation.

If those conditions are met, drafting should begin.
Do not wait for exhaustive coverage.

## Minimum Shared Research Package

Before or alongside individual entry work, assemble one shared package that can be reused across all three pilot entries.

### Shared input 1: user-job anchor
Write one short sentence for each concept answering:
- what live wording, translation, or framing decision this entry is supposed to help with;
- what a user might get wrong if they rely on literal translation.

This is required because the entries are meant to support practical decisions, not only describe semantic differences.

### Shared input 2: reusable source pool
Use a shared pool first, then add entry-specific sources only if needed.

Minimum shared source pool:
- 1 German institutional or political source class used across the pilot set where possible
- 1 German journalism or commentary source class used across the pilot set where possible
- 1 English institutional, policy, or explanatory source class used across the pilot set where possible
- 1 English journalism or commentary source class used across the pilot set where possible

The point is not that the same exact outlets must appear in every entry.
The point is to reduce sprawl and keep the pilot set legible to reviewers.

### Shared input 3: comparison rule
For each pilot entry, compare how the term functions in serious public usage across German and English.
Do not try to prove full institutional equivalence between political systems.
Do not expand into a general history of the term unless the warning or recommendation would otherwise be incoherent.

### Shared input 4: drafting stop rule
Stop research and move to drafting once the entry can support:
- one plain-language mismatch summary;
- one framing-risk note;
- one false-equivalence warning or explicit statement that none is needed;
- one practical translation recommendation;
- two traceable examples.

If the entry still feels impossible within that boundary, treat that as a design warning rather than a prompt for unlimited research.

## Entry-Level Minimum Inputs

Each pilot entry should begin with the same bounded input structure.

### Required inputs per entry
1. **User-job note**
   - one to three sentences describing the concrete decision the entry helps with.
2. **Provisional mismatch hypothesis**
   - one sentence stating the likely translation or framing problem to test.
3. **German evidence set**
   - 2 promising sources maximum for the first pass;
   - at least 1 source should show public, political, legal, or policy usage rather than dictionary explanation.
4. **English evidence set**
   - 2 promising sources maximum for the first pass;
   - at least 1 source should show how the apparent equivalent functions in English-language public usage.
5. **Context clarifier**
   - 1 short note or source that explains the institutional, historical, or civic nuance most likely to be missed in literal translation.
6. **Drafting claim check**
   - one sentence each for:
     - what seems genuinely shared across the two terms;
     - what seems mismatched;
     - what advice a writer or translator may need.

This keeps the first pass to roughly 5 source objects per entry at most:
- 2 German
- 2 English
- 1 context clarifier

That is enough to produce a credible draft without turning the pilot into a research program.

## Pilot Entry Research Inputs

## 1. `Solidarität` / `solidarity`

### What must be clarified before drafting
- whether the German term is functioning mainly as social obligation, labor-linked cohesion, welfare-state justification, or movement rhetoric in the chosen examples;
- whether the English term in the chosen examples sounds more activist, moral, or movement-oriented than the German usage being compared;
- when literal translation is acceptable because the moral overlap is doing the real work;
- when literal translation is misleading because it shifts the register away from institutional or policy context.

### Minimum inputs
- **User-job note:** identify one realistic case where a writer must decide whether `Solidarität` should remain `solidarity` or be glossed more contextually.
- **German evidence:**
  - 1 institutional, party, union, or welfare-context usage;
  - 1 journalism or commentary example showing how the term is framed in public language.
- **English evidence:**
  - 1 movement, labor, or public-commentary usage of `solidarity`;
  - 1 policy-adjacent or explanatory usage if available.
- **Context clarifier:**
  - a short note on whether the mismatch is mostly about moral tone, institutional embeddedness, or political register.

### What can wait
- a full history of solidarity discourse;
- wide survey of philosophical theories of solidarity;
- corpus-scale mapping of movement versus institutional usage.

### Drafting readiness test
The entry is ready once the project can state, with examples:
- one place where direct translation works;
- one place where `solidarity` sounds too movement-coded or too thin for the German use;
- one practical warning sentence a writer could reuse.

## 2. `soziale Marktwirtschaft` / `social market economy`

### What must be clarified before drafting
- whether the German term is being used as a historically loaded institutional formula rather than a generic description of moderated capitalism;
- whether English `social market economy` in the selected sources preserves that specificity or functions mainly as explanatory shorthand;
- what misunderstanding appears when a writer treats the English phrase as self-explanatory.

### Minimum inputs
- **User-job note:** identify one realistic case where a writer needs to decide whether to translate literally, preserve the German, or add a gloss.
- **German evidence:**
  - 1 party, government, or official institutional use of `soziale Marktwirtschaft`;
  - 1 German explanatory or journalistic source that reveals its political baggage or historical loading.
- **English evidence:**
  - 1 English source using `social market economy` directly in comparative, journalistic, or policy explanation;
  - 1 English source that explains or paraphrases the German idea without assuming the phrase is transparent.
- **Context clarifier:**
  - a short note on the minimum historical or institutional baggage that must be preserved for the entry to remain honest.

### What can wait
- a full ordoliberalism literature review;
- exhaustive postwar economic history;
- broad comparative welfare-capitalism taxonomy.

### Drafting readiness test
The entry is ready once the project can show:
- why literal translation is sometimes necessary but often insufficient;
- what short gloss preserves the missing context best;
- one concrete false-equivalence risk a reviewer could recognize immediately.

## 3. `Staatsbürgerschaft` / `citizenship`, with `Bürgersinn` boundary note

### What must be clarified before drafting
- which selected German uses are clearly legal or status-based and therefore map reasonably well to `citizenship`;
- where nearby discourse drifts toward civic virtue, public-mindedness, or civic ethos and therefore points toward `Bürgersinn` or a gloss rather than plain `citizenship`;
- how to stop the entry from collapsing legal membership and civic character into one English label.

### Minimum inputs
- **User-job note:** identify one realistic case where a writer must decide whether `citizenship` is enough or whether the German source is invoking a broader civic ideal.
- **German evidence:**
  - 1 legal, governmental, or parliamentary use of `Staatsbürgerschaft`;
  - 1 civic-education, commentary, or adjacent public-use example that helps define the boundary with `Bürgersinn` or related civic language.
- **English evidence:**
  - 1 legal or policy use of `citizenship`;
  - 1 English-language use showing whether the term expands toward civic participation, belonging, or public virtue.
- **Context clarifier:**
  - a short boundary note explaining when the problem is translation of legal status versus translation of civic ethos.

### What can wait
- a full comparative citizenship-theory review;
- deep nationality-law comparison across multiple jurisdictions;
- a full side essay on republicanism, civic virtue, or democratic theory.

### Drafting readiness test
The entry is ready once the project can show:
- one context where `citizenship` is a clean rendering;
- one context where `citizenship` is too narrow or too broad;
- one short note explaining why `Bürgersinn` is not just a synonym to be merged casually into the same English label.

## Research That Can Wait Until After the First Drafts

The following work is useful but should not block the pilot entries:
- larger concept-adjacency mapping across all 8 MVP terms;
- diachronic history for each concept;
- academic literature review beyond what is needed to avoid a misleading claim;
- systematic corpus collection;
- formal taxonomy of ideological traditions behind each term;
- broader multilingual expansion;
- polished issue prompts or reviewer packets derived from the pilot entries.

Those tasks become relevant after the first drafting pass reveals where the real uncertainty or utility sits.

## Minimum Output Expected from the Research Pass

Before each pilot entry moves into drafting, the research pass should leave behind:
- a short user-job note;
- a provisional mismatch statement;
- a bounded source list;
- two traceable example candidates;
- one context clarifier;
- one sentence on what the draft should warn against.

If those items exist, the drafting worksheet should be used immediately.

## Red Flags

Treat the pilot concept as at risk if the first research pass keeps requiring:
- more than two rounds of source expansion before any practical guidance can be written;
- long background explanation just to make the term understandable;
- unresolved dependence on adjacent concepts before one entry can stand on its own;
- claims about national political culture that cannot be tied to the selected examples.

If these red flags appear, tighten the claim before expanding the research.
Do not compensate for a weak entry design with more reading.

## Immediate Follow-On Use

This note should now constrain three follow-on tasks:
1. the implementation-ready concept note;
2. the first drafting pass for the three pilot entries;
3. the first issue prompts or contribution packets derived from those entries.

## Working Conclusion

The smallest credible research package for the pilot set is not exhaustive evidence.
It is a bounded, reusable, source-traceable package that gives each entry enough material to make one honest mismatch claim, one practical recommendation, and one reviewable warning.
