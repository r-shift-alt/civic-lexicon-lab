# Lexicon Pilot Entry Issue Packet

## Purpose

This packet turns the first three lexicon pilot drafts into a contributor-facing review surface that is small enough for a new GitHub contributor to use immediately.

The goal is not open-ended theory discussion.
The goal is to collect bounded review on:
- wording choices;
- source fit;
- false-equivalence warnings;
- places where the practical guidance is still too vague.

## Review Object

Review these three draft entries:
1. `11_ARTIFACTS/LEXICON_SOLIDARITAET_ENTRY_DRAFT.md`
2. `11_ARTIFACTS/LEXICON_SOZIALE_MARKTWIRTSCHAFT_ENTRY_DRAFT.md`
3. `11_ARTIFACTS/LEXICON_STAATSBUERGERSCHAFT_ENTRY_DRAFT.md`

These three were chosen because they test three different kinds of translation risk:
- moral and movement register drift;
- historically loaded institutional language;
- legal-status language that can blur into civic-virtue language.

## What Useful Help Looks Like

A strong contribution usually does at least one of these:
- points to a sentence where the current warning is too weak, too broad, or too abstract;
- suggests a tighter practical recommendation a writer or translator could actually reuse;
- identifies a source example that fits better than one already used;
- shows where the draft overstates mismatch or understates genuine overlap;
- marks a place where a literal translation is safer or riskier than the current draft claims.

Please keep contributions:
- traceable;
- specific;
- bounded to the current entries;
- grounded in actual usage, editing judgment, or translation practice.

## Out of Scope

Please do not use this packet to:
- reopen the whole project strategy;
- argue for manifesto expansion;
- propose many new concepts at once;
- turn one pilot entry into a full theory essay;
- replace source-backed claims with intuition alone.

## Shared Review Questions

Contributors reviewing any of the three entries should focus on these questions:
1. Does the draft identify a real translation or framing problem you recognize?
2. Is the mismatch summary too strong, too weak, or about right?
3. Is the warning sentence actually usable in live writing, editing, or translation work?
4. Do the current examples support the claim being made, or is a better source needed?
5. What should be cut because it adds analysis but not practical use?
6. What single change would make the entry more reusable right now?

## Issue Prompt 1: `Solidarität`

### Suggested GitHub issue title
`Review pilot entry: Solidarität / solidarity`

### Why this entry matters
This draft is testing a register problem rather than a hard dictionary mismatch.
The current claim is that English `solidarity` is usually close, but can sound more movement-coded or exhortative than German `Solidarität` when the German text is doing quieter institutional work around social protection, collective obligation, or labor-linked cohesion.

### Where review is most needed
Please check whether the draft gets these judgments right:
- when plain `solidarity` is fully sufficient;
- when a modifier or gloss is needed;
- whether the current warning overstates the activist tone of English usage;
- whether the examples adequately support the institutional-versus-movement register distinction.

### Most useful contribution shapes
- suggest one tighter wording improvement to the mismatch summary;
- identify one better English example for institutional or policy-facing `solidarity`;
- flag one place where the practical guidance is still too vague for an editor on deadline.

## Issue Prompt 2: `soziale Marktwirtschaft`

### Suggested GitHub issue title
`Review pilot entry: soziale Marktwirtschaft / social market economy`

### Why this entry matters
This draft is testing a historically loaded institutional term.
The current claim is that `social market economy` is usually the correct English translation, but that the bare English phrase often sounds too generic unless the writer restores the term's German postwar and institutional baggage with a short gloss.

### Where review is most needed
Please check whether the draft gets these judgments right:
- when literal translation can stand alone;
- when a restoring gloss is necessary;
- whether the entry makes the postwar-German load clear without becoming an economic-history detour;
- whether the English examples show what ordinary readers are likely to hear from the phrase.

### Most useful contribution shapes
- suggest one sharper gloss formula for public-facing writing;
- identify one strong English-language journalism or commentary example;
- flag one place where the draft collapses into generic `capitalism with safety nets` language.

### Entry link
`11_ARTIFACTS/LEXICON_SOZIALE_MARKTWIRTSCHAFT_ENTRY_DRAFT.md`

## Issue Prompt 3: `Staatsbürgerschaft`

### Suggested GitHub issue title
`Review pilot entry: Staatsbürgerschaft / citizenship`

### Why this entry matters
This draft is testing a boundary problem.
The current claim is that English `citizenship` is usually correct when the German source is about legal membership, but English also stretches more easily into civic-participation, education, and public-virtue language that may be better matched in German by something other than plain `Staatsbürgerschaft`.

### Where review is most needed
Please check whether the draft gets these judgments right:
- when `citizenship` is a clean legal-status translation;
- when English civic-language drift needs a qualifier, paraphrase, or term switch;
- whether the draft keeps the legal-status core clear enough;
- whether the boundary note on `Bürgersinn`-type language is concrete rather than hand-wavy.

### Most useful contribution shapes
- identify one strong German example that marks the shift from legal status to civic ethos more clearly;
- suggest one tighter warning sentence for editors handling mixed legal and civic language;
- flag one place where the draft risks overcomplicating a context where plain `citizenship` is already enough.

### Entry link
`11_ARTIFACTS/LEXICON_STAATSBUERGERSCHAFT_ENTRY_DRAFT.md`

## Optional Cross-Entry Issue

### Suggested GitHub issue title
`Cross-entry review: wording and false-equivalence warnings in the first lexicon pilot set`

### Prompt
Read all three pilot drafts and answer:
- Which warning sentence is most reusable as written?
- Which draft is currently most useful for a real writing or translation decision?
- Which draft is still too analytical relative to its practical value?
- Where is the evidence strongest, and where does one better source example matter most?
- What format change would improve all three entries at once?

This cross-entry issue is especially useful for editors, translators, or policy writers who can compare the whole pilot set as a working format rather than reviewing only one concept.
